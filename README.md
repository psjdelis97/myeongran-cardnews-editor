# 명란 요리 카드뉴스 편집기

야마야 「명란 요리 맛있게 만드는 법 5가지」 인스타 카드뉴스(7장)를 브라우저에서 보면서 고치고 PNG로 저장하는 편집기.

- 바로 열기: https://psjdelis97.github.io/myeongran-cardnews-editor/
- 할 수 있는 것: 카드 크기 · 형식(사진 배경 / 글+사진) · 사진 교체·비율·위치 · 폰트(기본 16종 · 폰트 파일 · 내 컴퓨터 폰트) · 색 · 문구 수정 · PNG 다운로드
- 수정 내용은 각자 브라우저에만 저장된다.
